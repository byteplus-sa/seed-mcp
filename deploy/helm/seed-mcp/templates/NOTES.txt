This chart runs database-free BYOK HTTP with at least two application pods.
No PostgreSQL, Redis, SQLite, state volume, schema or database Secret is required.
Source rendering is not release approval or capacity certification.
NEVER upgrade a live SQLite release without a separately reviewed transition:
an upgrade can delete removed resources. Preserve old release metadata, disks,
WAL/database backups, identity and accepted IDs for reconciliation.
CSI is not a new application prerequisite; retain existing addons and volumes.

Verify CCM, two Ready nodes with surge/draining capacity, private API access,
DNS/TLS, identity/TLS Secrets and metrics API before acknowledging prerequisites.
HPA is 2-6 pods by default. All rate and concurrency limits are PER POD.
There is no daily budget ledger or durable deduplication/replay. Configure
provider-side spend limits and save task IDs on clients. Never repeat uncertain creates.
Only /mcp and /health are public. /ready and metrics remain private.
Temporary upload preparation is disabled by default. If enabled, verify the
distinct existing TOS/enrollment Secret and private versioning-disabled bucket,
prefix IAM, browser POST CORS, lifecycle and storage/egress controls separately.
The client uploads bytes directly; MCP only signs. See docs/temporary-uploads.md.
Roll pods after external Secret changes; no Secret-content checksum is available.
