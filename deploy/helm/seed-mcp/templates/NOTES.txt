This chart runs database-free BYOK HTTP with at least two application pods.
No PostgreSQL, Redis, SQLite, state volume, schema or database Secret is required.
Source rendering is not release approval or capacity certification.
This is a fresh stateless deployment, with no historical database compatibility
or stateful-release migration tooling. Local stdio storage is separate.
CSI is not a new application prerequisite; addons remain administrator-owned.

Verify CCM, two Ready nodes with surge/draining capacity, private API access,
DNS/TLS, identity/TLS Secrets and metrics API before acknowledging prerequisites.
HPA is 2-6 pods by default. All rate and concurrency limits are PER POD.
There is no daily budget ledger or durable deduplication/replay. Configure
provider-side spend limits and save task IDs on clients. Never repeat uncertain creates.
Only /mcp and /health are public. /ready and metrics remain private.
